# FAGASA Loan Management System

**Role:** Full-Stack Developer
**Type:** Enterprise-grade Microfinance Management Platform

## 🌟 Project Overview
The FAGASA Loan Management System is a production-ready, full-stack microfinance platform tailored for FAGASA Investment Ltd. It provides comprehensive tools to manage the complete lifecycle of microfinance operations, empowering organizations to handle client onboarding, group formation, loan disbursements, repayment tracking, savings management, treasury oversight, and compliance reporting seamlessly.

## 🚀 Key Features Built
*   **Comprehensive Loan Lifecycle Management:** Developed the end-to-end workflow for multiple loan products (Biashara, Emergency), including applications, simulation engines, approvals, disbursement, and automated installment scheduling.
*   **Advanced Analytics & Reporting:** Built dynamic Head Office and Branch dashboards featuring real-time charts (using Recharts) to track critical KPIs like Outstanding Loan Balance (OLB), Portfolio at Risk (PAR), and collection trends.
*   **Hierarchical Organizational System:** Implemented a robust multi-tier system managing Branches, Groups, and Clients, complete with dedicated, role-based dashboards for each level.
*   **Treasury & Finance Tracking:** Engineered a finance module for tracking treasury capital, liquidity, system accountability, payroll, and expenses.
*   **Robust Security & Compliance:** Integrated JWT-based authentication, Role-Based Access Control (RBAC), and comprehensive system audit logging tracking user actions, modules, and IPs.

## 🛠️ Technical Stack & Skills Acquired
*   **Frontend:** React 19, Vite 8, React Router DOM 7
*   **UI/UX:** Custom Vanilla CSS Design System featuring a premium dark-theme with glassmorphism aesthetics, responsive layouts, and Recharts for data visualization.
*   **Backend:** Python 3.12, Flask 3.0, Flask-RESTful architecture.
*   **Database & ORM:** SQLite, SQLAlchemy (Flask-SQLAlchemy), structured database migrations.
*   **Security & Auth:** Flask-JWT-Extended, Flask-Cors.
*   **AI Integration:** Developed an AI-assisted query endpoint for natural language portfolio analysis.

## 💡 What Makes This Project Stand Out
*   **Premium Design:** The application moves away from generic templates, utilizing a highly customized, glassmorphic dark UI that gives an immediate impression of a modern, high-value enterprise product.
*   **Real-world Complexity:** Handled complex financial logic including PAR aging (Portfolio at Risk), repayment amortizations, and yield forecasting.
*   **Production Readiness:** Complete with audit trails, data seeders, structured database migrations, and broadcast messaging systems for staff.

## 📈 Impact
Designed to digitize and streamline traditional microfinance processes, reducing manual errors, improving collection tracking accuracy, and providing executive leadership with instant visibility into portfolio health and branch performance.
